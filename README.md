# Merry Christmas by Anwesha

An interactive Christmas card made for phones: a grain tree that lights up under your finger, a little gift game, and a Christmas poem.

**Live:** https://byanwesha-funsies.github.io/merry-christmas-by-anwesha/

## Personal cards
Add a name to the end of the link and the card greets that person:
`https://byanwesha-funsies.github.io/merry-christmas-by-anwesha/#priya`

## Making changes
Everything lives in `index.html`. Edit it on GitHub (pencil icon) or locally, commit, and GitHub Pages republishes the site automatically in about a minute.

## Your link
The share link is set by `SITE_URL` in `index.html`.
